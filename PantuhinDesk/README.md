# Pantuhin Desk

Desktop-приложение WinForms для базы из `backup2pantuhin.sql` (PostgreSQL).

## Состав

- Вход для администратора, менеджера и пользователя; самостоятельная регистрация пользователей.
- Хеширование новых паролей PBKDF2. При первом успешном входе пароль из исходного backup автоматически заменяется хешем.
- Заявки: пользователь создаёт и отслеживает свои; менеджер принимает в работу и завершает; пользователь подтверждает получение; администратор редактирует/удаляет.
- Справочник работников: просмотр для пользователя, полный CRUD для администратора.
- Администратор может создавать учётные записи менеджеров и просматривать роли и аккаунты.
- Поиск по описанию, статусу, логину пользователя и менеджера; фильтр по статусу; составная сортировка по дате/статусу/пользователю.
- ID создаются приложением, в формах не редактируются; статус и специальность задаются фиксированными списками.
- Экспорт текущего результата поиска/фильтрации в XLSX и PDF.
- Тёмная тема с акцентным цветом, скруглёнными карточками, полями и кнопками. Фильтры и полоса прокрутки таблицы оформлены отдельно, без белых системных элементов.
- Экран входа обновлён. Между разделами «Заявки» и «Личный кабинет» приложение переключается с коротким плавным сдвигом.
- Личный кабинет показывает роль, логин, ID, данные профиля и количество заявок; пароль можно сменить из профиля.
- Поиск, фильтры и сортировка работают по локальному кэшу; текстовый поиск применяется с небольшой задержкой, чтобы не обращаться к базе на каждый символ.

## Запуск

1. Установите PostgreSQL и восстановите предоставленный дамп, например:

   ```powershell
   createdb -U postgres pantuhin
   psql -U postgres -d pantuhin -f "C:\путь\к\backup2pantuhin.sql"
   ```

2. При сборке шаблон `appsettings.example.json` автоматически копируется рядом с приложением как `appsettings.json`. Откройте файл в папке запуска, обычно `bin\Debug\net8.0-windows\appsettings.json`, и задайте пароль PostgreSQL вместо `CHANGE_ME`.
3. Соберите и запустите на Windows с установленным .NET 8 SDK:

   ```powershell
   dotnet run
   ```

4. Для первого входа используйте существующие аккаунты из backup. В исходном дампе присутствуют `admin1`/`pass1`, `manager1`/`pass1`, `user001`/`password001`. Смените исходные пароли при первом входе.

`appsettings.json` содержит пароль базы данных — не публикуйте его и не добавляйте в систему контроля версий.

## Примечания по исходным данным

В текстовых полях backup часть кириллицы закодирована как UTF-8, повторно прочитанный в Windows-1251. Приложение исправляет такие строки при отображении. Новые значения сохраняются в Unicode. Старые статусы преобразуются в отображаемый вид; статусные фильтры работают в приложении и не зависят от испорченного исходного значения.

Роли определяются таблицей аккаунта, через которую выполнен вход. Регистрация создаёт только пользователя; менеджеров добавляет администратор. Администратор из backup остаётся доступен для управления приложением.
